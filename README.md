# NOX

Ứng dụng học từ vựng và ngữ pháp tiếng Anh: thẻ ghi nhớ (Flashcard), luyện viết (Writing), luyện nghe (Listening), và cẩm nang ngữ pháp (Grammar).

## Tính năng chính
- **Thẻ ghi nhớ (Flashcard):** Chế độ Lật thẻ và Chế độ Đọc danh sách tiện lợi.
- **Luyện viết (Writing):** Hỗ trợ gợi ý từ, đọc phát âm câu mẫu, tự động kiểm tra đáp án.
- **Luyện nghe (Listening):** Giao diện hội thoại tương tác, luyện nghe chép chính tả.
- **Ngữ pháp (Grammar):** 46 Unit ngữ pháp hệ thống hóa, hỗ trợ tra cứu và đánh dấu.
- **Kho dữ liệu (Warehouse):** Quản lý danh sách từ, thống kê tiến độ, xuất/nhập sao lưu JSON.
- **Giao diện đa dạng:** Hỗ trợ nhiều chủ đề màu sắc, đặc biệt là Giao diện Hiện đại (Modern Dark Navy).
- **Hỗ trợ PWA:** Hoạt động offline mượt mà thông qua Service Worker.
