Đổi database
Phiên bản & Cập nhật
Hướng dẫn tạo database mới
  1. Vào console.firebase.google.com, đăng nhập bằng tài khoản Google muốn dùng.
  2. Nhấn Add project, đặt tên rồi tạo dự án (có thể tắt Google Analytics cho nhanh).
  3. Vào Build → Realtime Database → Create Database, chọn khu vực gần bạn, chọn Test mode để bắt đầu nhanh.
  4. Vào biểu tượng ⚙ Project settings → General, kéo xuống mục Your apps, nhấn biểu tượng Web </> để thêm 1 Web App.
  5. Đặt tên rồi nhấn Register app — Firebase sẽ hiện đoạn code chứa object firebaseConfig.
  6. Copy toàn bộ nội dung trong dấu { } đó, dán vào ô "Đổi database" trong Nox rồi nhấn Áp dụng.

Lưu ý: cần để Realtime Database ở chế độ cho phép đọc/ghi (Test mode, hoặc tự chỉnh Rules) thì Nox mới đồng bộ được. Nhấn "Về mặc định" bất cứ lúc nào để quay lại database gốc của Nox.

Đã có bản cập nhật mới cho Nox.
